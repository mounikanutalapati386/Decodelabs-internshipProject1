# Iris Flower Classification using K-Nearest Neighbors (KNN)

## Overview

This project is part of the Decode Labs Artificial Intelligence Internship. The objective is to classify Iris flower species using the K-Nearest Neighbors (KNN) Machine Learning algorithm.

The model predicts whether a flower belongs to Setosa, Versicolor, or Virginica based on its sepal and petal measurements.

## Features

* Iris Dataset Classification
* Data Preprocessing using StandardScaler
* Train-Test Split for Model Evaluation
* K-Nearest Neighbors (KNN) Algorithm
* Accuracy Score Calculation
* Confusion Matrix Generation
* Classification Report Analysis
* Interactive User Prediction System

## Technologies Used

* Python
* Scikit-Learn
* NumPy

## Workflow

1. Load Iris Dataset
2. Preprocess and Scale Data
3. Split Data into Training and Testing Sets
4. Train KNN Model
5. Predict Flower Species
6. Evaluate Model Performance
