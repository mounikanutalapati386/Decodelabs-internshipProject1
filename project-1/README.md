# DecodeLabs Internship Project 🤖

## Project Overview

This project is a simple AI-based chatbot developed using Python as part of my internship at DecodeLabs. The chatbot is designed to interact with users through predefined conversational responses, creating a basic simulation of human-like communication.

The project focuses on understanding core programming concepts such as conditional statements, loops, dictionaries, functions, random response generation, and user interaction handling in Python.

## Features

* Interactive text-based chatbot
* Smart predefined responses
* Randomized replies for natural conversation
* Beginner-friendly and easy-to-understand code
* Console-based user interaction
* Simple AI conversation flow

## Technologies Used

* Python
* VS Code
